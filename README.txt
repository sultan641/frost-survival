# Frost Survival Website — Sultan

## Files
- `index.html`: home page with four game cards and all community links.
- `wos-v4.html`: Whiteout Survival V4 page and gift codes.
- `v5-europe.html`: Whiteout Survival V5 Europe page, promoter code 16365, iOS notice, and 37 gift codes.
- `v5-china.html`: Whiteout Survival V5 China page and gift codes.
- `kingshot-v4.html`: KingShot V4 page and gift code.

## Publish on GitHub Pages
1. Extract this ZIP.
2. In your GitHub repository, upload all five `.html` files to the repository root (same folder as the current `index.html`).
3. Replace existing `index.html` when GitHub asks. Commit the changes.
4. Open the GitHub Pages website and refresh.

The site is static and works without a database. The gift-code search and copy buttons run in the browser. The update report sections contain starter text; add real dated reports when you have them.
