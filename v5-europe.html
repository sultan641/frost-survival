📲 Additional Private Server Installation Guide

These are extra troubleshooting instructions. Keep the original installation guide above and read every file, note, and instruction supplied with your selected game version before installing.

04 · Read the version files and check existing installs

Read all files and installation instructions provided for this exact version. If you already have another build of the same game installed — such as V4, V5, the official version, or another private-server version — uninstall the conflicting version before installing this one. First make sure your account is bound and your progress can be recovered. Do not delete unrelated personal files.

06 · Install the private-server version

After the file has downloaded, open it and follow Android's installation prompts. Use only the file and download link provided for this exact game version. If Android asks for permission to install from that source, review the prompt and allow it only if you trust the file.

07 · Last option if nothing else works

If the steps above still do not work, first make sure your official-game account is safely bound and your progress is recoverable. Then uninstall the official game, open the private-server download through the OneDrive website in your browser, download the file there, and try installing the private-server version again. Once the private-server version is installed and working, you may reinstall the official game. Whether both versions can remain installed depends on their package compatibility.
