🔐 Android: Allow restricted settings

If Android blocks an app permission, open Settings → Apps → Universal 4X → tap the three-dot menu (⋮) → Allow restricted settings. Follow the on-screen confirmation, then return to the app and enable only permissions you trust.

The menu may differ by Android version. Only allow restricted settings for an app you trust.
